Question 4.1
Vulnerability scans can, by nature, be somewhat network-intensive. In the event that a host being 
actively scanned becomes unresponsive, something like Nessus could DoS the system even further. 
What can be configured within the scan to prevent this from happening?
 - By enabling the "Stop scanning hosts that become unresponsive during the scan" setting in Nessus. 

Question 4.2
What is the default user-agent for Nessus web application scanning? 
 - The default user-agent for Nessus web application scanning is Mozilla/4.0 (compatible; MSIE 8.0; Windows NT 5.1; Trident/4.0)

Question 4.3
What type of port scanning does Nessus perform by default?
 - Nessus uses SYN port scanning by default.
